# pairwise-lightmap-uv-chart

烘焙出来的墙角有一道黑缝，UV 岛之间没有 dilation，相邻岛的暗部渗到墙面上；两个岛在光照贴图里重叠，最后一笔烘焙覆盖了前一笔；接缝两侧的纹素没做缝合，同一面墙被切成两块后亮度差一档；第二套 UV 由自动展开生成，接缝处切线方向不一致；纹素密度按整张图统一，小物件占了同样面积却糊成一片；图集打包按包围盒，旋转后的岛与未旋转的岛互相压边；HDR 光照贴图存成 8bit，窗边高光被削平后反弹到室内变成灰；烘焙时场景里有未标记的静态物体，它被烘进图里但运行时又在移动；图集边缘没有 clamp，远处墙面采样到图外变成黑边；重新烘焙只更新了直接光，间接光还是上一版。render/lightmap_uv_chart.py 是核心，tests/test_lightmap_uv_chart.py 15个红。要修的是：岛外扩 dilation；重叠检测；接缝纹素缝合；切线统一；按物体定纹素密度；旋转后再打包；HDR 浮点存储；静态标记校验；边缘 clamp；直接间接一起重烘。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
